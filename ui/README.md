# Gothic UI Redesign - Project3

## Overview
Complete visual redesign of Inventory UI and Upgrade Bench UI to match a dark gothic aesthetic inspired by Bloodborne, Witchfire, and Dark Souls.

## Architecture

### Shared Resources
- `ui/resources/` - Shared StyleBox textures, themes, and visual resources
- `ui/gothic_theme.tres` - Global Gothic Theme
- `ui/gothic_styles.gd` - Helper functions for creating gothic-styled elements

### Inventory UI
- `ui/InventoryUI.cs` - Complete rewrite with gothic visuals
- `ui/InventoryUI.tscn` - Scene with gothic layout

### Upgrade Bench UI
- `ui/UpgradeBenchUI.cs` - Complete rewrite with ritual table aesthetics
- `ui/UpgradeBenchUI.tscn` - Scene with gothic layout

## Style Guide
- Colors: Dark charcoal, bronze, ancient gold, crimson, dark blue
- Typography: Serif fonts (Bloodborne/Dark Souls inspired)
- Textures: Parchment, stone, scratched metal, leather
- Animations: Book-opening, magical reveal, card rise
- Effects: Particle dust, embers, subtle glow
